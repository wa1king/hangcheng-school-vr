Changes for this site: unused cabin nodes are detached, the license plate
geometry is reduced to a plain blue panel, paint/glass/rubber are adjusted,
brake lights get a separate material, and the meshes are simplified and
compressed with gltfpack 1.3.0. The geometry is oriented and batched at runtime.

The preferred source files for making these changes are the original GLB
archive above together with the following source file in this project's
public source repository:
https://github.com/wa1king/hangcheng-school-vr/blob/main/tools/prepare_street_vehicles.py

To rebuild, run:
    python tools/prepare_street_vehicles.py openx-assets-glb.zip <scratch>

Then, for each of corolla and tucson, run:
    npx --yes gltfpack@1.3.0 -i <scratch>/<model>-prepared.glb -o public/scene/street-vehicle-<model>.glb -cc -vpf -vp 15 -vn 10 -kn -km -si 0.48 -se 0.008 -sv -sp
